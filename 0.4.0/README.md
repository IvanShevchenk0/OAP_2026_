# Лабораторна робота №4 — версія 0.4.0

Ця версія реалізована як SPA з фронтендом на TypeScript і бекендом на Express + SQL.js.

## Структура
- `index.html` — основна сторінка, що завантажує зібраний `dist/app.js`.
- `app.ts` — фронтенд-логіка, робота з формами, таблицями, фільтрацією та деталями.
- `apiClient.ts` — типізований HTTP-клієнт з підтримкою таймауту та стандартних ProblemDetails-помилок.
- `shared/dtos.ts` — загальні типи DTO між фронтендом і бекендом.
- `backend/src` — серверна частина Express, маршрути, сервіси, репозиторії, обробка помилок.

## Запуск фронтенду
1. Перейдіть у папку `0.4.0`.
2. Встановіть залежності:

```bash
npm install
```

3. Зберіть фронтенд:

```bash
npm run build
```

4. Відкрийте `index.html` у браузері або сервируйте папку `0.4.0` через локальний веб-сервер.

> Скрипт збирання компілює `app.ts` та `apiClient.ts` у `dist/app.js` і `dist/apiClient.js`.

## Запуск бекенду
1. Перейдіть у папку `0.4.0/backend`.
2. Встановіть залежності:

```bash
npm install
```

3. Запустіть сервер у режимі розробки:

```bash
npm run dev
```

4. Або зберіть і запустіть продакшн:

```bash
npm run build
npm run start
```

Сервер доступний за адресою `http://localhost:3000`.

- `PUT /api/v1/software/:id`
- `DELETE /api/v1/software/:id`

### Версія 0

- `GET /api/users`
- `GET /api/categories`

## Особливості реалізації
- Фронтенд використовує модульні імпорти та типи з `shared/dtos.ts`.
- Клієнт `apiClient.ts` обробляє JSON відповідь, викидає `ApiClientError` при неуспішному HTTP-статусі.
- Бекенд підтримує CORS і централізовану обробку помилок через middleware.
- На фронтенді реалізовано фільтр по ліцензії, пошук, редагування, видалення і деталі ПЗ.
- У бекенді є alias маршрути для `/api/v1/...` і `/api/...`.

## Нотатки
- Щоб фронтенд працював, `index.html` повинен завантажувати зібраний `dist/app.js`.
- У `backend/src/services/software.service.ts` типи DTO беруться з `shared/dtos.ts`.
